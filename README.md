# 関西ドローンスポット帳

関西2府5県（大阪・兵庫・京都・奈良・滋賀・和歌山・三重）のドローン飛行スポット一覧です。

https://uhouho628.github.io/kansai-drone/

- note・アメブロ・個人ブログ・ドローン系メディア・SNS・自治体の公式情報などから候補を集め、646か所に整理
- 管理者の扱い（練習施設・申請や連絡が必要・要確認・禁止・閉鎖）と、国のルール（人口集中地区・空港・重要施設の周囲おおむね1,000m）を分けて表示
- 人口集中地区（DID）は e-Stat の令和2年国勢調査 人口集中地区境界データと代表座標で判定
- 無料・有料、府県、種類、情報源で絞り込み可能
- リストとマップを切り替え可能（地理院タイル、DIDの範囲を重ねて表示）
- 観光地／観光地以外でも絞り込み可能

ルールや営業状況は変わります。飛ばす前に必ず管理者・国土交通省（DIPS 2.0）・地理院地図で確認してください。このページは法律の助言ではありません。
